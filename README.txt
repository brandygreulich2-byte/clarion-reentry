CLARION COUNTY REENTRY RESOURCE CENTER - PUBLIC PROTOTYPE

Open index.html in your browser to preview. This static site includes a working keyword search, category filter, and printable release checklist. It collects and transmits no user data. Checklist state resets on reload.

PUBLISH FREE:
1. Create a free GitHub account.
2. Create a PUBLIC repository named clarion-reentry.
3. Upload index.html from this folder to the repository root.
4. In repository Settings > Pages, choose Deploy from a branch, main, /(root), Save.
5. Your site will be at https://YOUR-USERNAME.github.io/clarion-reentry/ once published.

IMPORTANT: This is a prototype, not an official county site. Confirm organizational permission before using county branding. Verify all resources before launch. Do not collect client records or sensitive referral information on a public static website.
