Community outreach toolkit

Help local organizations review public resource listings and share this independent directory with people preparing for reentry. Inclusion does not imply endorsement, partnership or guaranteed eligibility.

Invite resource verification

Share the public resource verification form with organizations. Ask for public-facing service descriptions, phone numbers, eligibility, hours and official URLs only.

Invite public events

Use the event listing template. Events are reviewed manually; submissions do not automatically appear online.

Introduce the project

Use the editable introduction letter and printable flyer.

How information gets published

  1. Organization sends only public information through its own established contact channel.
  2. Website editor checks source and records the status.
  3. Editor updates the static website and tests links.
  4. Organization is invited to review the published entry.

No automated submissions or confidential referrals are accepted through GitHub Pages.
